## Запуск в облачной сессии

Эти шаги заменяют пункты протокола про ручной вход, `save_to_disk`, `zoom` и `/chrome`.

```
pip install playwright                                   # в контейнере есть только Chromium
curl -sS -o /dev/null -w "%{http_code}\n" https://edu-dev.istok.systems/   # ждём 200/30x, не 000
python3 istok-audit/tools/browser.py start --width 1920 --height 1080
python3 istok-audit/tools/browser.py open /login
python3 istok-audit/tools/browser.py shot SIM-00-00      # стартовое состояние /login
python3 istok-audit/tools/browser.py login
```

Соответствие протоколу:

| Протокол | Облачная сессия |
|---|---|
| человек входит вручную | `browser.py login`: значения берутся из переменных окружения, не печатаются |
| `save_to_disk` | `browser.py shot <ID>` или `browser.shot(page, ID)` → `screenshots/<ID>.png` |
| `zoom` на опечатку | `shot <ID> --selector CSS --zoom 3 --mark`: область вокруг элемента, красная рамка |
| ширины 1920/1366/1024 | `browser.py size 1366 768`, команда сообщает о горизонтальном скролле |
| консоль и сеть | пишутся автоматически; `browser.py log --sim N` → переносить в `console.md` |
| «попроси человека закрыть модальное окно» | закрыть самому, если это не меняет состояние аккаунта; иначе остановиться и спросить |
| `/chrome` → Reconnect | `browser.py stop`, `start`, `login`; продолжать по этому файлу |

Состояние браузера (профиль с cookie, журнал консоли) лежит в `~/.istok-audit-state`, вне репозитория.
Отчёт: `python3 istok-audit/tools/build_report.py` (промежуточный — `--sims 1-7`).
